📝 to-do-list
Uma lista de tarefas simples e elegante desenvolvida com HTML, CSS e JavaScript puro.

✨ Funcionalidades

Adicionar tarefas com o botão + ou pressionando Enter
Marcar tarefas como concluídas clicando nelas
Deletar tarefas com o botão ✕
Campo de input limpo após adicionar tarefa

🛠️ Tecnologias

HTML5
CSS3
JavaScript

🎨 Design
Visual escuro e moderno com borda em gradiente azul, seguindo o padrão do portfólio pessoal.
🚀 Como usar

Clone o repositório:

bashgit clone https://github.com/seu-usuario/to-do-list.git

Abra o arquivo todo.html no navegador.
Digite uma tarefa e pressione Enter ou clique em + para adicionar! 📝

Pronto! Não precisa instalar nada. 😄
